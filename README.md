# gsplat-examples

A lightweight fork of [gsplat](https://github.com/nerfstudio-project/gsplat) that keeps only the `examples` directory and the original Apache-2.0 LICENSE.
Perfect for learning, experimenting, or integrating gsplat usage patterns without pulling in the full repo.

### 🔄 Changes

This fork includes updates from [npu-chenlin:main](https://github.com/npu-chenlin/gsplat) (see PR [#536](https://github.com/nerfstudio-project/gsplat/pull/536)), which improves compatibility with the latest [pycolmap](https://colmap.github.io/pycolmap/index.html).
